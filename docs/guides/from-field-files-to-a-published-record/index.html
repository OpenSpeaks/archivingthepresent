Guide

From field files to a published record

Subhashish Panigrahi

ARK https://n2t.net/ark:86534/atp-g-000001

This guide shows how to use three OpenSpeaks tools one after another. Bento renames your source files. Subtitler helps you write subtitles. Tome describes the finished file and publishes it. All three run in a web browser and are free to use.

The workflow at a glance

Each tool does one job. Use them in this order:

  1. Keep the originals. Copy every file off the camera or phone before you change anything.
  2. Rename the source files in Bento. Every file gets a name that says what it is.
  3. Make smaller copies in Bento. Use these for sharing and subtitling.
  4. Write subtitles in Subtitler. Save the subtitle file with the same name as the video.
  5. Edit the film. See Module 04. The result is the produced file.
  6. Describe and publish in Tome. Tome writes the metadata, the agreements and the final file name.

Source files are what came out of the camera. Produced files are edited and ready to publish. Bento and Subtitler work on source files. Tome works on produced files.

The worked example: Sarda-Sora, September 2026

Let's take the example of a real project: a recording of Sarda-Sora by Opino Gomango in September 2026. Sarda-Sora is a variety of the Sora language spoken in Rayagada district, Odisha, India. Its ISO 639-3 code is srb, the code for Sora. The interviewed speakers are Ratnagar Sabaro, Ramchandra Sabaro, Injuram Sabaro and Horaboti Gomango.

Opino Gomango recorded them in three sets:

  • School: four videos with Ratnagar Sabaro, a school secretary.
  • Book: one video with Ramchandra Sabaro, secretary of the Sompeng Matarbanum. Four videos with Injuram Sabaro, a retired teacher, about the books he wrote in Sora. There are also 34 photos of Injuram Sabaro with those books.
  • Temple: three videos and eight photos at a temple. Horaboti Gomango speaks in two of the videos.

The files came to us with the camera's own names, such as IMG_8404.MOV and _DSC0088.JPG. We then needed a spreadsheet to say which file was which. This guide uses these files to show each step. Near the end, we list what we had to fix.

Before you start: keep the originals

  1. Copy all files from the camera or phone to one folder per recording session.
  2. Make a second copy on another drive or in cloud storage.
  3. Don't rename, compress or edit these originals. Every tool below works on copies.
  4. Download each file once. Repeated downloads leave copies such as IMG_8404-002.MOV.

Check the date and time on your camera before you record. The date in each file comes from the camera clock. A wrong clock gives every file a wrong date.

Step 1: rename source files in Bento

  1. Open Bento and go to the Organise tab.
  2. Choose Field recordings.
  3. Add the files from one session and one speaker.
  4. Fill in the language code, the speaker's initials, the date and the category.
  5. Keep Add sequence number and Use lowercase file extension ticked.
  6. Click Generate Rename Plan and check every new name.
  7. Click Export CSV. Keep this file with the recordings.
  8. Click Rename & Download ZIP.

A Bento name has five parts with _ between them: language code, speaker's initials, date, category and number.

Ratnagar Sabaro and Ramchandra Sabaro have the same initials. We added a letter from each first name (RtS and RcS) so their files can't be mixed up.

Photos and videos go in separate batches, because each batch takes one category. Each batch starts its numbers at 001.

The CSV rename plan replaces a hand-made list. It holds each old name, its new name, its type and its size.

Step 2: check lengths and make smaller copies

  1. Bento passes the renamed files to the Duration and Compress tabs.
  2. In Duration, check the length of each recording. Export the list if you need it for a report or for payment.
  3. In Compress, make smaller MP4 copies of the videos for sharing and subtitling.

A compressed copy keeps the same name with a different extension: srb_IS_20260910_interview_001.mp4. Share the originals too. For the School recordings, only compressed copies were shared, so the source files weren't in the archive.

Step 3: write subtitles in Subtitler

  1. Open Subtitler and load the compressed copy.
  2. Choose the language of the subtitles.
  3. Write the subtitles. Follow the Text Style Guide: 3 to 7 seconds and up to 45 characters for each subtitle.
  4. Download the file as SRT.
  5. Name it after the video, adding the language code: srb_IS_20260910_interview_001.en.srt.

Keep subtitle files in a Subtitle folder with the same subfolders as the videos. In the Sarda-Sora case these are Subtitle/Book and Subtitle/School.

Step 4: describe and publish in Tome

Edit the film first, following Module 04. Then open Tome with the produced file.

  1. Load the produced file, or its Wikimedia Commons page if it's already published.
  2. Fill in the people, the language, the place, the date and the topic.
  3. Fill in the consent and agreement details. See Module 02.
  4. Add the subtitle files.
  5. Choose a licence.
  6. Save the record as a file. You can open it again later.
  7. If the community has agreed to it, publish to Wikidata and Wikimedia Commons from the last tab.

Tome gives the produced file a longer name, with full names and the topic. It uses hyphens between parts, for example: srb-Sora-Opino Gomango-Injuram Sabaro-Writing books in Sora.webm. Bento gives the same name in its Upload-ready mode.

What we fixed in the Sarda-Sora files

Problems found and how to avoid them
What happenedHow to avoid it
Files arrived with camera names, and a spreadsheet was typed later to explain them.Rename in Bento before sharing. Share the CSV rename plan.
The spreadsheet listed subtitle file names where the video names should be.Use one row for each source file. Put the subtitle file in its own column.
IMG_8399.MOV was left out of the spreadsheet.Check the rename plan against the folder before sharing.
The School videos were shared only as compressed copies. IMG_8336.MOV wasn't shared at all.Share the originals as well as the copies.

Folder names ended in a space, and photo extensions were mixed (.HEIC and .heic).Bento uses lowercase extensions. Type folder names with no space at the end.
The files didn't name the speaker in the Temple videos. We had to ask who she was.Write down each speaker's name, in their own spelling, when you record.
