Guide

From field files to a published record

Subhashish Panigrahi

ARK https://n2t.net/ark:86534/atp-g-000001

Use three OpenSpeaks tools in this order. Bento renames your recordings and makes smaller copies. Subtitler helps you write subtitles. Tome describes the finished film and publishes it. All three are free and run in a web browser.

Overview

  1. Keep the originals.
  2. Rename recordings in Bento.
  3. Make smaller copies, also in Bento.
  4. Write subtitles in Subtitler.
  5. Edit the film. See Module 04.
  6. Describe and publish in Tome.

Original recordings are the files that came out of the camera or phone. The edited film is what you publish. Bento and Subtitler work on the original recordings. Tome works on the edited film.

Keep the originals

  1. Before you record, check the date and time on your camera or phone. Each file takes its date from this clock.
  2. Write down who speaks in each recording, with their name spelt the way they spell it. Note the place and date too. See practical steps during recording.
  3. After recording, copy all files to one folder for each recording session.
  4. Make a second copy on another drive or in cloud storage.
  5. Don't rename, compress or edit the originals. Every step below works on copies.

For more on keeping files safe, see Module 04.

Rename recordings in Bento

A camera name such as IMG_0001.MOV doesn't say what the file is. Bento gives each file a name with five parts:

language code_speaker's initials_date_category_number

  1. Open Bento and go to the Organise tab.
  2. Choose Field recordings.
  3. Add the files from one session and one speaker.
  4. Fill in the language code, the speaker's initials, the date and the category.
  5. Keep Add sequence number and Use lowercase file extension ticked.
  6. Click Generate Rename Plan and check every new name.
  7. Click Export CSV. Keep this file with the recordings. It lists each old and new name.
  8. Click Rename & Download ZIP.

Rename photos and videos separately. If two speakers have the same initials, add a letter from each first name.

Example

An interview in Sora (code srb) with a speaker whose initials are AB, recorded on 10 September 2026, becomes srb_AB_20260910_interview_001.mov.

Make smaller copies

Large video files may not open in Subtitler, and they're slow to share.

  1. In Bento, open the Duration tab to see how long each recording is. Export the list if you need it for a report or for payment.
  2. Open the Compress tab and make smaller MP4 copies of the videos.
  3. Use the copies for subtitling and sharing. Keep the originals for the archive.

Example

srb_AB_20260910_interview_001.mov gets the smaller copy srb_AB_20260910_interview_001.mp4.

Write subtitles in Subtitler

  1. Open Subtitler and load the smaller copy.
  2. Choose the language of the subtitles.
  3. Write the subtitles. Keep each one on screen for 3 to 7 seconds, with up to 45 characters. See the Text Style Guide.
  4. Download the file as SRT.
  5. Give it the video's name, with the subtitle language code before .srt.

Keep all subtitle files in one Subtitle folder.

Example

English subtitles for srb_AB_20260910_interview_001.mp4 are saved as srb_AB_20260910_interview_001.en.srt.

Describe and publish in Tome

  1. Open Tome and load the edited film.
  2. Fill in the people, the language, the place, the date and the topic. See Module 05.
  3. Fill in the consent and agreement details. See Module 02.
  4. On the Subtitles tab, tick the parameters of the Oral Knowledge Framework that the film follows, to record consent, community review and subtitles.
  5. Add the subtitle files and choose a licence.
  6. Save the record as a file, so you can open it again later.
  7. If the community agrees, publish to Wikidata and Wikimedia Commons from the Commons tab. See Module 06.

Tome gives the film a longer name, with the language, full names and the topic.

Common mistakes

Common mistakes and how to avoid them
What goes wrongHow to avoid it
Files are shared with camera names, and someone has to work out later which file is which.Rename in Bento before sharing. Share the CSV with the files.
The date in the notes doesn't match the date of the file.Check the camera clock before recording. Use the date from the file.
A compressed copy has the same name as the original, so nobody knows which is which.Keep originals in their own folder. Make copies in Bento, which changes the extension.
Only the smaller copies are shared.Share the originals as well.
Repeated downloads leave duplicate files, folders and ZIP files.Download once. Compare file sizes before keeping a second copy.
Folder names end in a space, or extensions are mixed (.HEIC and .heic).Type folder names with no space at the end. Bento uses lowercase extensions.
Subtitles are shorter than 3 seconds and hard to read.Follow the Text Style Guide.
Nobody wrote down who speaks in a recording.Note each speaker's name when you record.
A person's name or role is written differently in different files.Ask each person how they spell their name and what their role is. Use that everywhere.
