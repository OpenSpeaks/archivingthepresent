Guide

From field files to a published record

Subhashish Panigrahi

ARK https://n2t.net/ark:86534/atp-g-000001

This guide shows how to use three OpenSpeaks tools one after another. Bento renames your source files. Subtitler helps you write subtitles. Tome describes the finished file and publishes it. All three run in a web browser and are free to use.

The examples come from recordings of Sarda-Sora, a variety of the Sora language spoken in Rayagada district, Odisha. Opino Gomango made them in September 2026. Its language code is srb. The common mistakes at the end are the problems we found in those files.

This guide goes with the manual's modules on recording, file managing and editing, metadata and publication.

Overview

Each tool does one job. Use them in this order:

  1. Keep the originals.
  2. Rename source files in Bento.
  3. Check lengths and make smaller copies, also in Bento.
  4. Write subtitles in Subtitler.
  5. Edit the film. See Module 04.
  6. Describe and publish in Tome.

Source files are what came out of the camera or phone. Produced files are edited and ready to publish. Bento and Subtitler work on source files. Tome works on produced files.

Keep the originals

  1. Check the date and time on your camera or phone before you record. Each file takes its date from this clock.
  2. After recording, copy all files to one folder for each recording session.
  3. Make a second copy on another drive or in cloud storage.
  4. Don't rename, compress or edit the originals. Every tool below works on copies.
  5. Download or copy each file once. Repeated downloads leave extra copies, such as IMG_0001-002.MOV.
  6. Write down who speaks in each file, with the name spelt the way they spell it, and the place and date. See practical steps during recording in the Oral Knowledge Framework.

Module 04 covers keeping files safe and making backups.

Example

One School video, IMG_8332.MOV, had three copies on Google Drive. Only one was the camera original (301 MB). The other two were smaller copies made by re-encoding, with the same name. We kept the original.

Rename source files in Bento

Camera names such as IMG_0001.MOV don't say what a file is. Bento gives each file a name with five parts, joined by _:

language code_speaker's initials_date_category_number

  1. Open Bento and go to the Organise tab.
  2. Choose Field recordings.
  3. Add the files from one session and one speaker.
  4. Fill in the language code, the speaker's initials, the date and the category.
  5. Keep Add sequence number and Use lowercase file extension ticked.
  6. Click Generate Rename Plan and check every new name.
  7. Click Export CSV. Keep this file with the recordings. It lists each old name, its new name, its type and its size.
  8. Click Rename & Download ZIP.

The renamed files and the CSV make a file map: one row for each source file. Add the speaker, the content and the subtitle file in columns next to it. Module 05 explains what else to describe.

Put photos and videos in separate batches, because each batch takes one category. If two speakers have the same initials, add a letter from each first name.

Example

Injuram Sabaro's interview video IMG_8400.MOV became srb_IS_20260910_interview_001.mov. A photo of him, IMG_8405.HEIC, became srb_IS_20260910_other_001.heic.

Ratnagar Sabaro and Ramchandra Sabaro both have the initials RS, so their files use RtS and RcS.

Check lengths and make smaller copies

  1. Bento passes the renamed files to the Duration and Compress tabs.
  2. In Duration, check the length of each recording. Export the list if you need it for a report or for payment.
  3. In Compress, make smaller MP4 copies of the videos for sharing and subtitling.

A smaller copy keeps the same name with a different extension. When you share files, share the originals as well as the copies. An archive needs the originals. If you pay speakers or documenters by recording length, see fair, equitable remuneration.

Example

The iPhone videos were too large to open in Subtitler, so Opino Gomango made MP4 copies to subtitle. They're working copies, and the archive keeps the originals. With Bento, srb_IS_20260910_interview_001.mov gets the smaller copy srb_IS_20260910_interview_001.mp4.

Write subtitles in Subtitler

  1. Open Subtitler and load the smaller copy.
  2. Choose the language of the subtitles.
  3. Write the subtitles. Follow the Text Style Guide: 3 to 7 seconds and up to 45 characters for each subtitle.
  4. Check the timing before you download. Cues shorter than 3 seconds are hard to read.
  5. Download the file as SRT.
  6. Name it after the video, and add the code of the subtitle language before .srt.

Keep subtitle files in a Subtitle folder, with the same subfolders as the videos.

Example

English subtitles for srb_IS_20260910_interview_001.mp4 are saved as srb_IS_20260910_interview_001.en.srt.

Describe and publish in Tome

Edit the film first, following Module 04. Then open Tome with the produced file.

  1. Load the produced file, or its Wikimedia Commons page if it's already published.
  2. Fill in the people, the language, the place, the date and the topic.
  3. Fill in the consent and agreement details. See Module 02.
  4. Switch on the Oral Knowledge Framework to record who may access the recording and how the community benefits.
  5. Add the subtitle files.
  6. Choose a licence.
  7. Save the record as a file. You can open it again later.
  8. If the community has agreed to it, publish to Wikidata and Wikimedia Commons from the last tab.

Module 05 covers metadata, and Module 06 covers where and how to publish.

Tome gives the produced file a longer name, with full names and the topic, joined by hyphens. Bento gives the same kind of name in its Upload-ready mode.

Example

Opino Gomango's film of Injuram Sabaro, a retired teacher who wrote books in Sora, is named srb-Sora-Opino Gomango-Injuram Sabaro-Writing books in Sora.webm.

Common mistakes

We found each of these in the Sarda-Sora files in November 2026.

Common mistakes, what happened in the Sarda-Sora files, and how to avoid them
What goes wrongIn the Sarda-Sora filesHow to avoid it
Files are shared with camera names.All 54 files kept names such as IMG_8404.MOV. We built a spreadsheet afterwards to say which file was which.Rename in Bento before sharing. Share the CSV rename plan.
The date in the notes doesn't match the file.The notes said the School videos were from 10 September. The files show 9 September.Check the camera clock before recording. Take the date from the file.
A re-encoded copy has the same name as the original.IMG_8332.MOV had three copies. Two were smaller re-encodes.Keep originals in their own folder. Give copies a different extension or folder.
Repeated downloads leave duplicates.About 4.5 GB of duplicates: a second IMG_8404.MOV, a second book folder and a ZIP file of the same files.Download once. Compare file sizes before keeping a second copy.
Folder names end in a space.The folders were book  and Temple , with a space at the end.Type folder names with no space at the end.
Extensions are mixed.Photos ended in both .HEIC and .heic.Bento uses lowercase extensions.
Subtitle files are scattered.Subtitles sat in a Subs folder inside each set.Keep them in one Subtitle folder with the same subfolders as the videos.
Subtitle cues are too short.A check found 577 timing problems in 1,031 cues, mostly cues under 3 seconds.Follow the Text Style Guide and check timing in Subtitler.
Nobody wrote down who speaks.The notes didn't name the speaker in the Temple videos. We had to ask who she was.Write down each speaker's name when you record.
Names and roles differ between files.The subtitles spell one speaker's name differently from the notes. The notes gave another speaker's role as president. He's the school secretary.Ask each person how they spell their name and what their role is. Use that everywhere.
