# Privacy

This site collects no personal data. It uses no cookies, analytics, or tracking scripts of any kind. The only interactive element is a download link for the manual's PDF, which is served as a static file with no form or account required. No visitor information is stored anywhere by this project. If a future feature (such as a network sign-up form) starts collecting information, this page will be updated to describe exactly what is collected and why before that feature goes live.
